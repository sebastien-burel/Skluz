Ce programme désinstalle Skluz

Il ne s'installe rien : l'Installateur de macOS nomme son bouton « Installer », mais cliquer dessus lance la désinstallation.

Seront supprimés :

  • le service système de Skluz et ses tunnels Système, arrêtés proprement ;
  • l'app /Applications/Skluz.app, quittée chez chaque utilisateur ;
  • la commande skluz (/usr/local/bin/skluz).

Sont conservés, sauf si vous cochez l'option dans « Personnaliser » :

  • la configuration système : tunnels Système, clés dédiées et clés d'hôte approuvées, pour qu'une réinstallation les retrouve.

Les tunnels Session de chaque utilisateur ne sont jamais touchés.
